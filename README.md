# Jobs and Interns Invoice Studio

Create, track and share invoices, quotations and receipts for Jobs and Interns, in the brand's red theme.

- Overview dashboard with billed, collected, outstanding and overdue figures
- Editor with live A4 preview, four templates, QR code, signature and PDF export
- Clients and a recruitment service catalogue (job posts, shortlisting, campus outreach, promotions)
- Payments, receipts, JSON backup/restore and CSV export

Everything is a single `index.html`. Data is stored in the browser only, so export a backup from Settings to move to another device.

Enable GitHub Pages on this repository to host it.
